# EKA World — Hridova

Standalone React/Vite world for EKA.

## Run

```powershell
npm install
npm run dev
```

## Included

- EKA main world with profile card, centered character scene, quote card and bottom action row
- Talk, Chat, Play, Sleep, Music, Explore and Settings panels
- Separate EKA character asset with transparent background
- Mood-based game catalogue
- Ten sleep stories with browser speech synthesis
- Mood-based music player using files in `public/eka/music/`

## Music filenames used by the player
